# Week 1 — Cloud Fundamentals & Account Setup

The AWS root user is the original identity associated with an AWS account and has complete access to the account, so it should only be used for tasks that specifically require root access. For everyday AWS work, I use an IAM user instead of the root user. IAM allows AWS permissions to be assigned to users, groups, and roles so that access can be controlled more securely. I created an IAM administrator user for this training environment and configured the AWS CLI to authenticate as that user. I also enabled MFA to add an additional layer of protection to account access. Under the AWS Shared Responsibility Model, AWS is responsible for security **of** the cloud, including the underlying infrastructure, while customers are responsible for security **in** the cloud, such as identities, permissions, data, and resource configurations. Understanding this separation helps me know which security responsibilities belong to AWS and which ones I must manage myself.
